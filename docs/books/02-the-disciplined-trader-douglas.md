## Главная идея

Трейдеры проигрывают не из‑за незнания индикаторов, а из‑за **неспособности управлять поведением** в неопределённости и риске.

| Обычная жизнь | Рынок |
|---------------|--------|
| Правила понятны | Правила неопределённы |
| Ошибки объяснимы | Рынок не обязан объяснять |
| Хочется быть правым | Нужны вероятности |
| Страх защищает | Страх мешает войти/выйти |
| Контроль полезен | Иллюзия контроля опасна |

---

## Главные идеи для EDGE

1. **Рынок не «хороший/плохой»** — сигнал ≠ обещание.
2. **Страх и надежда** — держат убыток, режут прибыль, revenge, пропуск сигналов.
3. **Риск принят до входа** — entry, SL, TP, invalidation, % risk.
4. **Дисциплина > гениальный анализ** — EDGE = scanner + **повторяемое исполнение**.
5. **Серия сделок** — оценка PREMIUM/STRONG на 50–100 сигналах, не на одном.

---

## Signal ≠ Entry (уровни)

| EDGE | Значение |
|------|----------|
| WAIT / NONE | нет |
| WEAK | слабый warning |
| MEDIUM | кандидат |
| STRONG / VERY_STRONG | сильный warning |
| PREMIUM + CONFIRMED | premium candidate → вход **только** с trigger |

Даже **PREMIUM** без trigger = **WARNING**, не сделка.
